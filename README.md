# M1 Traffic Speed Analysis for Manufacturing Logistics

## Overview

This project aims to analyze traffic speed data on the motorway in the UK, sourced from [trafficengland.com](https://www.trafficengland.com/traffic-report), to provide insights for logistics planning. The analysis focuses on understanding traffic patterns and identifying factors that influence speed, such as day of the week, time of day, roadworks, and congestion. This information is crucial for a major manufacturing organization to optimize delivery schedules and ensure timely client deliveries.

## Dependencies

* Python 3.x
* Pandas
* Scikit-learn
